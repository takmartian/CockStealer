AutoX.JS简介

AutoX.JS是一个基于Node.js的自动化测试框架，可以用于安卓应用及系统的自动化测试。

界面介绍

AutoX.JS的界面分为三个部分：

  • 主页：列出脚本文件夹内容。
  • 管理：列出当前正在执行的脚本以及已创建的定时任务。
  • 文档：官方文档

侧边菜单

  • 服务

  • 启用新编辑器：在APP内编辑脚本时所用的IDE编辑器版本（新版/旧版）。
  • 无障碍服务：当无障碍服务开启后，Autox才有权限操作屏幕、元素、系统控制等。
  • 稳定模式：没用过，请参考官方文档。
  • 通知获取权限：开启后可获取系统通知内容。
  • 前台服务：保持APP持续运行。
  • 使用情况访问权限：开启后，AutoX可获取设备使用情况。

  • 录制脚本

  • 悬浮窗：显示一个悬浮窗在屏幕表层，可以快速操作AutoX
  • 音量下键控制：录制脚本时可使用音量下按键控制开始/结束。
  • 自动备份脚本：脚本上传到云（不明真相上传到哪儿）

  • 其他

  • 连接电脑：使用IP/数据线与电脑进行socket连接，使用电脑操控手机端的AutoX。
  • 打开USB调试：可以通过USB数据线连接电脑进行调试，电脑需要安装ADO驱动，手机需要打开USB调试。
  • 设置：AutoX的软件设置。

主页

  • 示例代码

  • 此文件夹包含了APP自带的一些脚本示例，可以在此文件夹找到一些案例并参考。

  • 文件

  • 此处列出了AutoX资源文件夹中的脚本清单，图中DingTalk.js为我创建的一个js脚本。
  • 运行：脚本后方的三角按钮可运行该脚本。
  • 编辑：脚本后方的铅笔按钮可在APP中编辑该脚本。
  • 更多：脚本后方的···按钮可以对脚本进行更多操作。
  • ··· - 循环运行：设置脚本循环执行，可设置循环次数、循环间隔、开始运行前的延迟。
  • ··· - 定时任务：设置脚本定时执行，可设置每天在制定时间运行、只在某时间运行一次，按星期运行，广播触发运行。

管理

  • 运行中脚本

  • 此处显示当前正在运行的脚本，可以手动结束。

  • 定时任务

  • 此处显示已设置的定时任务，可对任务进行修改或删除。

脚本编写

AutoX.JS的脚本是基于JavaScript的，可以使用JavaScript的语法进行编写。

AutoX.JS提供了一些API供脚本调用，如：click()、swipe()、text()等。

脚本编写的过程中，可以使用AutoX.JS的IDE进行调试，也可以使用其他IDE进行编写，然后导入到AutoX.JS中。

官方文档：http://doc.autoxjs.com/

基本API

AutoX.JS提供了一些API供脚本调用，如：

  • click()：点击屏幕上的某个元素。
  • swipe()：滑动屏幕。
  • text()：输入文本。
  • back()：返回。
  • home()：返回主页。
  • power()：锁屏。
  • sleep()：等待x毫秒。
  • 更多API参考官方文档。

示例代码

以下是一个简单的AutoX.JS脚本示例：

            
// 引入AutoX基础模块
const appName = "YourApp"; // 替换为你的应用名称
const userName = "username123";
const password = "password123";

// 启动应用并等待加载完成
console.log("启动应用: " + appName);
if (!launchApp(appName)) {
    console.error("无法启动应用，请检查应用是否安装");
    exit();
}
waitForPackage(appName, 20000);
console.log("应用启动成功");

// 定位到登录页面
if (text("登录").exists()) {
    console.log("定位到登录页面");
} else {
    console.error("未找到登录页面");
    exit();
}

// 输入用户名和密码
setText(0, userName);
setText(1, password);
console.log("输入用户名和密码");

// 点击登录按钮
if (text("登录").clickable()) {
    text("登录").click();
    console.log("点击登录按钮");
} else {
    console.error("登录按钮不可点击");
    exit();
}

// 等待登录成功
sleep(2000);
if (text("主页").exists()) {
    console.log("登录成功，进入主页");
} else {
    console.error("登录失败，请检查凭证");
    exit();
}

// 模拟滑动操作
swipe(500, 1500, 500, 500, 500);
console.log("页面向上滑动");

// 选择一个条目并点击
if (text("项目").exists()) {
    text("项目").click();
    console.log("进入项目页面");
} else {
    console.error("未找到项目页面");
}

// 进行延迟和确认截图操作
sleep(1000);
if (images.requestScreenCapture()) {
    let screenshot = images.captureScreen();
    console.log("截图成功");
    images.save(screenshot, "/sdcard/AutoX/screenshot.png", "png", 100);
} else {
    console.error("截图失败");
}

// 定位到某个具体的文本并进行点击
if (text("完成").exists()) {
    text("完成").click();
    console.log("点击完成按钮");
} else {
    console.error("未找到完成按钮");
}

// 延迟3秒，结束脚本
sleep(3000);
console.log("脚本执行完毕");
exit();

VS Code 插件

AutoX提供了VSCode插件，可与手机连接并实时调试。

插件安装方法

在VSCode中插件面板搜索autox，找到图中的插件安装即可。

连接手机

在VSCode中按下Cmd/Ctrl+Shift+P，唤起命令行，输入start server，选择启动autox服务：

启动成功后IDE右下角会提示连接的IP和端口：

手机打开AutoX并连接手机，输入IP和端口，或者扫描二维码进行连接即可。

调试

创建好js文件，编写好脚本，点击右上角的三角按钮，即可在设备上测试脚本。

右键点击文件可以将文件存储到设备中。
